
  # This is a national conference website for cluster and clean energy.

  This is the website of the cceccconference briefing researchers, students and stakeholders of the neccessity of cluster clean energy and climate change and providing neccessary details about the forthcoming conference in April, 2027.
  

This website has been developed with a clean tech aesthetic, featuring optimized layouts for mobile networks, a security honeypot for bot prevention and dedicated sections for the 2026 conference archives and proceedings.

## Tech Stack & Prerequisites
Before running the project locally, ensure you have the following installed on your machine:
* node.js (v18.0 or higher recommended)
* npm (comes bundled with node.js)

## Getting started
Follow these steps to set up and run the project locally in a development environment:

## 1. Extract the files
Unzip the project folder onto your local machine and open your terminal (or command prompt) inside the root project directory.

## 2. Install Dependencies
Run the following command to download and install all the necessary packages and styling libraries (including Tailwind Css components):
```bash
npm install
```

 ## To Launch the local development server, 
 ``` bash
 npm run dev
 ```

 ## To run the development server,
 ``` bash
 http://localhost:5173
 http://localhost:3000
 ``` 
 open this link in any browser to preview the live site.

 # Live Deployment to GoDaddy
 When you are ready to compile the code into highly optimized, minified HTML, CSS and JavaScript for live server deployment, run:
 ``` bash
 npm run build
 ```
 This will generate a production-ready folder named "dist" or "build" at the root of the project.


 For further technical inquiries regarding this deployment, please contact the developer or the conference administration at editorial@ccecconferences.com
